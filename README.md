# Annular liquid jets: exact constraint absorption and finite-time loss of global admissibility

Solvers, drivers and data for the paper

> F. R. Villatoro, *Annular liquid jets: exact constraint absorption and
> finite-time loss of global admissibility*, revised submission to *Physics of Fluids* (2026).

Version **v1.1.0** accompanies the revised manuscript.  It preserves the
v1.0.0 calculations and adds the diagnostics requested during peer review:
global-admissibility detection, an independent finite-difference cross-check
of the first interior contact, local contact characterisation, componentwise
off-grid residuals, temporal-tolerance and periodicity tests, a linear
frequency-response calculation, and a finite-thickness closure-absorption
audit.

## Main revision result

For the principal body-force calculation (`A=0.5`, `St_g=0.5`), the first
loss of physical admissibility is an **interior contact** rather than loss of
transversality at the tracked endpoint.  The converged spectral calculations
give approximately

```
t_c   = 10.7538
eta_c = 0.9509
S(t_c,1) = 0.484
```

so the endpoint remains transversal when the interior minimum first reaches
zero.  At contact the interior zero is quadratic.  The independent upwind
finite-difference formulation converges to the same first-contact time.

The data supporting these statements are in `data/revision_*.csv`.  The
revised Figures 2 and 5 are generated by `drivers/make_revision_figures.py`.

## Quadrature correction in v1.1.0

If `S_N` has degree `N`, then `R_N=(1-eta)S_N` can have degree `N+1` and
`R_N^2` degree `2N+2`.  The de-aliased enclosed-volume calculation therefore
uses an `N+2` point Gauss--Legendre rule, which is exact through degree
`2N+3`, instead of the `N+1` point rule used in v1.0.0.  The revision drivers
quantify the effect of this correction.

## Reading the residual tests

The off-grid residual is an a posteriori **spatial** consistency diagnostic.
The revision reports each equation separately, its normalisation and the
excluded nozzle neighbourhood.  Temporal error is assessed independently by
tolerance refinement and by comparison of DOP853 and Radau event times.

## Finite thickness

The revised package also checks the exact algebraic absorption of the
finite-thickness endpoint closure through

```
R_i = R - beta*m/(2*R) = (1-eta)*Sigma,
R   = (R_i + sqrt(R_i**2 + 2*beta*m))/2.
```

The non-stationary physical results reported in the paper remain the membrane
case (`beta=0`); the finite-thickness dynamic calculation is included as a
constraint-absorption verification.
